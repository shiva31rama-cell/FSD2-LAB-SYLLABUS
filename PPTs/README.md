# PPTs — FSD2 Lab Presentations

Each experiment has:

- `*.pptx` — editable PowerPoint file.
- `*_Preview.pdf` — GitHub-readable version of the same presentation.

The presentations use a consistent 16:9 layout, readable text, short points, clean code blocks, workflow visuals, runtime walkthroughs, expected-result checks and viva questions.

**To view a presentation directly in GitHub, open its `*_Preview.pdf`.**
