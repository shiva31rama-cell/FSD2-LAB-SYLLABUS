# MongoDB University Certification Guide

The syllabus includes MongoDB University certification as one possible augmented program.

## Study pathway
1. Create a MongoDB University account.
2. Start an introductory MongoDB learning path.
3. Read lessons and complete hands-on checks.
4. Finish quizzes/assessments shown by the course.
5. Download the certificate from the platform when the course reports completion.

Use the MongoDB learning link listed in the supplied syllabus: https://learn.mongodb.com/learning-paths/introduction-to-mongodb
