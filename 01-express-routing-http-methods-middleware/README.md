# ExpressJS Routing, HTTP Methods, Middleware

## Syllabus tasks
- Define a route, handle routes, route parameters, query parameters and URL building.
- Accept data, retrieve data and delete a specified resource using HTTP methods.
- Show the working of middleware.

## Run
From the repository root: `node 01-express-routing-http-methods-middleware/app.js`
Open `http://localhost:3001`.

## Flow
Client request → Express route → middleware → handler → response.
