# Experiment 07 — Conditional Rendering, Lists and React Forms

## Aim

Demonstrate conditional rendering, list rendering/filter/removal, and controlled React form fields.

## Files needed

**Seven files:** `index.html`, the experiment `package.json`, `src/main.jsx`, `src/App.jsx`, and `src/components/ConditionalDemo.jsx`, `ListDemo.jsx`, `RegistrationForm.jsx`.

## Run

From repository root:

```bash
npm run react07
```

Open the Vite URL shown.

## Handout parts demonstrated in this app

- **Part (a), Conditional rendering:** ternary expression, logical AND, role selector and alternate panel text. Toggle details to show/hide a message.
- **Part (b), Lists:** map students to list items, filter by branch, remove a student immutably.
- **Part (c), Forms:** controlled text/email/password/number/date/select/radio/checkbox/textarea fields; submit validation; reset.

Try filtering to CSE, remove one student, then submit the form with blank fields. Fill the required fields and check the agreement to submit.
