# MongoDB Installation, Configuration and CRUD Operations

## Syllabus tasks
- Install MongoDB and configure Atlas.
- Perform CRUD operations using `insert()`, `find()`, `update()` and `remove()`.

## Run
Use `mongosh`. The file contains the syllabus names and the modern `insertOne`, `updateOne` and `deleteOne` equivalents.

Example: `mongosh < 10-mongodb-installation-configuration-crud/queries.js`
